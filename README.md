## Werkstatt

**Website.** HTML und CSS ohne Framework, gehostet auf GitHub Pages mit eigener Domain.

**Bildpipeline.** Python mit Pillow. Aus jedem Foto werden JPG und WebP, lange Kante höchstens 1600 px, unter 600 KB.

**Golf-Handicap-Rechner.** Entstanden, weil ich es nach der Runde wissen wollte.
